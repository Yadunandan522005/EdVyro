# EdVyro
# Data Analytics & Machine Learning Projects

This repository contains the projects completed as part of my **EdVyro Internship**, covering data analysis, business intelligence, customer segmentation, and executive analytics.

## Projects 

### Task 1 – Data Quality & Exploratory Analysis
- Performed data cleaning, validation, missing-value and duplicate checks using **Python, Pandas and NumPy**.
- Conducted exploratory data analysis using **Matplotlib and Seaborn**.
- Analyzed customer churn, tenure, charges, support tickets and contract types.
- Identified important customer churn patterns and generated data-driven insights.

### Task 2 – Business KPI Dashboard
- Built an interactive **Customer Churn Business KPI Dashboard using Power BI**.
- Created KPIs including **Churn Rate, Retention Rate, Revenue at Risk and Average Tenure**.
- Added interactive slicers and visualizations for contract type, payment method and customer tenure.
- Used **DAX measures** to calculate and present business metrics.

### Task 3 – Segmentation & Recommendation Model
- Developed a customer segmentation and risk-scoring model using **Python**.
- Segmented customers based on tenure, support tickets and customer spending patterns.
- Created customer risk categories such as **Low, Medium and High Risk**.
- Generated personalized recommendations for customer retention and engagement.

### Task 4 – Executive Analytics Capstone
- Developed an **Executive Customer Churn Analytics Dashboard using Power BI**.
- Presented key KPIs, churn patterns, revenue at risk, payment methods and support-ticket analysis.
- Added **Executive Recommendations and Limitations** based on the analysis.
- Designed the dashboard to provide clear, actionable insights for business decision-making.
